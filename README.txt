A LITTLE PLACE FOR YOU — QR LETTER WEBSITE

FILES
- index.html: the webpage and your letter
- style.css: colors, layout, and envelope design
- script.js: envelope interaction
- photos/: the five photos you uploaded, displayed in a scrapbook-style gallery

HOW TO PREVIEW ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html.
4. It should open in your browser. An internet connection is needed for the optional Google Fonts.

HOW TO PUT IT ONLINE FOR FREE USING GITHUB PAGES
1. Sign in or create an account at https://github.com/
2. Create a new public repository, for example: a-little-place-for-you
3. Upload index.html, style.css, and script.js to the repository's main page, and upload the entire photos folder with all five images. Keep the folder name and image filenames unchanged.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish the site. Your public website address will appear in the Pages section.

HOW TO MAKE THE QR CODE
1. Copy the published GitHub Pages website address.
2. Use a trusted QR-code generator and paste the website address.
3. Download the QR code as PNG or SVG.
4. Test it with your phone before printing or giving it to her.

PERSONALIZE THE LETTER
Open index.html in VS Code.
Find the paragraphs inside <div class="letter-body"> and edit them.
You can also change the heading, closing, and signature.

IMPORTANT
The QR code cannot be finalized until the website has a public URL.
Test the published website and QR code on a phone before the ceremony.
